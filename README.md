#  M3Y OmColor — Xed-Editor Theme

A Material You themed color scheme for Xed-Editor, with light and dark (AMOLED) modes, inspired by Porcelain colors.

- **Total defined colors:** 130+ per mode

- **Visual style:** Material You (Porcelain-inspired)
